From the first object to your own Flappy Bird.

A practical reference for understanding scenes, objects, and events in GDevelop 5 while building a simple flying and obstacle game.

01 · Project foundation

Core concepts

GDevelop organizes the game visually. Instead of writing everything in code, you combine objects, conditions, and actions.

01

Scene

A game screen or level. The project can have a game scene and a start scene.

02

Object

Anything that appears or participates in logic: bird, background, block, or text.

03

Event

A rule made of a condition and an action. It defines game behavior.

04

Collision

Checks whether two objects touched. It can determine when the player loses.

02 · Assembly

Game structure

The scene is made of a character, scenery, and obstacles. Each item has a clear role.

03 · Control

The character

1

2

3

4

Use a key or touch to make the bird jump.

04 · Visual logic

How to think about an event
